Bank Account Management System

📌 Project Overview

The Bank Account Management System is a console-based Java application developed to demonstrate Object-Oriented Programming concepts and basic banking operations.

🚀 Features

- Create and manage bank accounts
- Add accounts to the bank
- Search accounts using account number
- Deposit money
- Withdraw money
- Check account balance
- Transfer money between accounts
- Display account details
- Maintain transaction history
- Display all bank accounts

🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- IntelliJ IDEA

🧩 Project Structure

    ├── Main.java

🧠 OOP Concepts Used

- Classes and Objects
- Encapsulation
- Constructors
- Access Modifiers
- Methods
- ArrayList
- Object-to-object interaction

▶️ How to Run

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Open "Main.java".
4. Run the "main()" method.
5. The banking operations will be displayed in the console.
